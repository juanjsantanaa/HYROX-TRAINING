## 🧮 La matemática del sub-60

Para bajar de 60:00 hay que sumar tres bloques:

- **8 × 1 km a 4:05–4:10** → 32:40 – 33:20
- **Roxzone** (transiciones) → ≤ 3:00 total
- **8 estaciones** → ≤ 23:30 total (promedio ~2:55 por estación)

Todo el plan apunta a esos tres bloques.

## 📁 Cómo usar este repo

| Carpeta | Contenido |
|---|---|
| `training-plan/` | Estructura semanal y calendario de las 7 semanas |
| `exercises/` | Guía de las 8 estaciones: técnica, pesos y tiempos objetivo |
| `templates/` | Plantillas copiables para cada tipo de sesión y para el registro diario |
| `logs/` | Registro semanal real: qué se hizo, data de WHOOP y notas |

## 📋 Flujo de trabajo

1. Antes de entrenar: abre la plantilla del día en `templates/`.
2. Entrena con la plantilla como guía (tiempos, pesos, cues).
3. Después: copia la plantilla de registro (`templates/training-log.md`) en `logs/<semana>.md` y completa con tu data de WHOOP (recovery %, sueño, strain, RHR, HRV) + lo que pasó en la sesión.

## ⚠️ Regla de oro

El cuello de botella no es el volumen: **es el sueño**. 7,5 h en cama la noche antes de días de intervalos, circuito o simulación. Si dormiste < 6 h, baja la intensidad del día siguiente.
